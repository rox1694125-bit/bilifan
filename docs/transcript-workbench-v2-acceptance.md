## 能力边界

- 自动检查是异常提示，不是人工事实核实。10个固定样本不能证明所有视频语言、术语和遗漏均可识别。
- 本轮不宣称纳百川已消费新增质量字段，也没有新增飞书完成通知。
- 进程控制核对随机标记及内核启动身份。主动清空标记、脱离会话且早于任何归属观测的任意外部程序，超出非特权 POSIX 的绝对追踪能力；身份无法确认时暂停，不猜测 PID 并误杀。
- 重试发布保护普通失败并保留备份；两个重命名不是断电原子交换。极端断电后需保留并检查 backup 目录，不能盲目重放。
- 速度收益只报告实际缓存与调用计数；未知 token 保持未知，不估算费用或节省比例。
