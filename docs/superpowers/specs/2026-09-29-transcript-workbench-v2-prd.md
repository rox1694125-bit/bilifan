# Bilifan 逐字稿工作台 v2 PRD

用户已确认实施；基线91fc135；2026-09-29。

## 目标与决策

视频资料可追溯、忠于原意、便于阅读，兼顾个人、课程批量与飞书。默认流程：视频→字幕/转录→保存原稿→纠错/断句/分段→整理稿→按需导出。

原稿默认保留，整理稿默认生成，不添加解读、推断、建议或模板摘要。停止新主报告/图解/配图，历史报告和章节继续可读且不得被重试删除。需复查可阅读，导出默认跳过，显式纳入必须保留警告，不等于人工审核通过。重启继续未开始任务，paused保持，中断保留现场人工恢复。取消必须实际停止后才结束。飞书仅既有入队/Web查看，不新增短链、指令或通知。

不换模型，不增加默认AI审稿，不批量重生成历史，不直接写知识库。

## A 内容与可信度

- A1 原始JSON/TXT/SRT保留文本和时间，AI整理前保存；后续失败仍可下载。整理HTML/PDF为主阅读入口，两种稿件明确命名。
- A2 整理只做纠错、去重复口癖、断句/分段/标题，不增外部信息，不把不确定说成确定。章节可对照原稿并跳视频。
- A3 数字/单位/代码变化和大段未覆盖内容有定位提示，不宣称自动正确。标点/空白/合理口癖删除不应大量误报，以固定正反例校准。
- A4 URL/命令/代码不作强口语语言证据；人工选择优先，最多一次纠偏；冲突不能用“结果像已选语言”自证消除。无新音频预检或LLM审稿。
- A5 统一质量：未发现明显异常、需复查、不可用、未检查。字幕/Whisper做适用本地检查，旧缺字段不是通过。不可用保存原稿与诊断并停AI整理，可读疑似结果带警告继续。
- A6 Web、整理HTML/PDF、原TXT、bundle、每条JSONL质量一致；SRT不插假字幕，以附质量说明的下载包交付。
- A7 单条需复查默认明确未导出；批量跳过并列原因；显式纳入不抹警告。历史导出做现有资料支持的本地检查，缺证据仍未检查。只保证Bilifan携带字段，不承诺纳百川已消费。
- A8 成功=原稿+有效整理稿+HTML+bundle，PDF保持尽力/必须语义；无主报告正常。获取失败不伪造原稿。

## B 统一任务、取消、恢复

- B1 单条/合集/批量/飞书/历史重试共用持久FIFO；同outputs一次一项；忙时可提交，按job ID跟踪。
- B2 暂停只停后续调度，等待项立即取消；运行项先canceling，计算退出后才canceled并推进下一项。
- B3 重启继续未暂停queued，paused保持；中断显示位置/已保存内容/恢复动作；已完成不重算，飞书幂等不变。
- B4 JSON损坏/磁盘故障可见并停止调度，不静默清空/误报提交成功。创建后立即持久run_key，仅完整交付后更新latest成功指针，未完成在任务账本展示。
- B5 下载/Whisper/Codex使用可取消执行器，受控正常系统验收取消10秒内停止实际计算，未退出不能提前改状态。
- B6 发布前最后检查取消；短暂发布/回滚关键段不强杀；发布已完成则完成并说明取消太晚。
- B7 看护进程持跨进程执行锁，父Web退出后旧计算未清理不能开始新项；核对执行身份，不能只凭PID杀进程，不明确则暂停。CLI共用锁，遇忙提示，不入Web排队。
- B8 原子完成凭证处理“已发布、队列未写终态”崩溃，恢复不能重复生成。

## C 分块复用与指标

- C1 文章块通过schema/来源/时间校验后立即原子保存，失败/取消/重启后只补缺失/失效块；缓存不是质检。
- C2 展示总块/完成/本次命中/待处理数，高级操作可全部强制重整。
- C3 key覆盖实际完整prompt、provider/model、归一化/校验版本，来源和规则变化失效，不跨视频猜测；读缓存复验，损坏只重做对应块。
- C4 检查点与attempt指标置于隔离临时工作区之外，失败保留；最终组装渲染仍隔离，成功才发布，旧成果不损伤。
- C5 区分排队/计算，记录阶段耗时、模型调用/失败次数、命中、程序/规则版本；实际可得token才存，未知不是0，不虚构金额/收益或保存敏感完整日志。

## 接口和兼容

bundle保持v1，加quality/output profile；summary=not_generated/style空/chapters空/validation not_applicable。JSONL为video+整理段落，不制造summary chapter；chapter_id可null，带text_source/quality。历史report.html/pdf和chapters.json只读及URL有效；文章重试只清对应产物，新bundle不混旧结论，UI独立历史报告入口，不批量改HTML/PDF。

保留原提交/查询/取消/暂停/重试URL，允许queued并加按ID查；current/queue同账本投影不双计。持久operation=完整处理/重试及参数、来源、retry_of、输出策略。旧summarization别名=文章整理，不加report阶段。普通UI移除模板/图解/截图，旧CLI/API/飞书字段兼容接受并提示停用，不执行也不拒整批。

账本JSON v2，单写者锁，同目录临时写/flush/fsync/原子replace/上一有效备份；保留历史ID/来源/时间/幂等。旧queued按新策略，保留请求快照和迁移提示。稳定run身份绑定缓存；缓存、执行声明、指标不得进入客户文件/公开白名单/知识库。
